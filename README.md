# Estimation: BOQ to Excel (website)

Turns drawings (DWG, DXF, PDF), BOQs, specifications and images into a clean bill of quantities in Excel. Everything runs in your browser; files are not uploaded anywhere.

Open the site: https://akhileshkmr340-oss.github.io/estimation-web/

The DWG reader in `dwg/` is LibreDWG (GPL-3.0); see `dwg/NOTICE.txt`. Text recognition uses Tesseract (`ocr/`), PDF rendering uses pdf.js (`pdfjs/`).
